# Hammer and Hoard: test builds

This repository only holds playable builds of **Hammer and Hoard** for testers. There is no code here.

## Getting the game

Open **[Releases](../../releases)** and download the zip for your computer from the newest release (it's at the top):

- **Windows:** `HammerAndHoard-vX.Y.Z-windows.zip`. Unzip and run `HammerAndHoard.exe`. If SmartScreen warns, choose *More info*, then *Run anyway*.
- **macOS (Apple Silicon and Intel):** `HammerAndHoard-vX.Y.Z-macos.zip`. Unzip and drag *Hammer and Hoard* to Applications. The app isn't signed with an Apple Developer ID, so the first time, right-click it and choose *Open*. If macOS says it is damaged, run this once in Terminal:
  `xattr -cr "/Applications/Hammer and Hoard.app"`
- **Linux / Steam Deck (x86_64):** `HammerAndHoard-vX.Y.Z-linux.zip`. Unzip and run `HammerAndHoard.x86_64`. On the Deck, use Desktop Mode, or add it to Steam with *Add a Non-Steam Game*.

A new build appears here every time the game changes, so check back for the latest one. Your saves carry over between builds.

## Reporting bugs

If something breaks or feels off, open an **[Issue](../../issues)** and say which version you played (it's in the release name), what you were doing, and what happened. A screenshot helps a lot.
